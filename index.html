Things I've built.

  1. 01

    Coco English

    Live
    TypeScriptNext.js 15React 19SupabasePostgreSQLOpenAIAzure SpeechVercel

    An AI app for practicing spoken English. Students record a response, and the app transcribes it, checks whether it answers the prompt and uses the target pattern, then gives pronunciation feedback. I built it to replace the speech recordings I used to assign and collect one student at a time.

    The app runs on Next.js App Router with React Server Components and Server Actions, backed by Supabase/PostgreSQL with versioned SQL migrations. Separate authentication flows for teachers and students are enforced with row-level security. Azure Speech handles phoneme analysis, OpenAI handles evaluation and moderation, Vercel cron jobs run scheduled work, and a content-addressed TTS cache keeps paid API costs down.

    Backed by 1,200+ automated tests, including Playwright end-to-end coverage.
